- 通读 core/execution/services 关键实现后完成架构审查，输出优缺点+改进建议。
- 发现 P0 bug：BacktestWorkflow 节点 capability="InitBacktest"/"RunBacktestLoop"，但 BacktestInitSkill/BacktestLoopSkill 注册的是 "cap.init_backtest"/"cap.run_backtest_loop"，SkillService 无别名机制 → 回测流程必然 NodeFailed。

## 全量优化实施（用户要求"全部优化"，已完成）
- capability 统一为 cap.*（skill impl/standard workflow/tests 全改），修复回测断链 P0；CapabilityService 支持 id/name 双索引 + register_from_skill 自动同步；Knowledge 条目同步 cap.*；Runtime 启动时 _validate_capabilities fail-fast。
- 新增 faos/core/config.py Settings（FAOS_ENV/FAOS_CORS_ORIGINS/FAOS_API_KEY/节点超时重试/TTL）；FAOS_ENV=mock 跳过真实 Provider（离线确定性）。
- Runtime 拆分 _register_default_services + create_runtime 工厂；任务完成/失败后 TTL 回收 contexts+active_tasks（默认 600s，上限 1000）。
- EventBus：handler 任务强引用追踪 + 异常捕获 + unsubscribe + stop 时 drain。
- Engine：节点超时（默认 300s）+ 指数退避重试（默认 1 次）+ NodeRetrying 事件。
- ExecutionContext 写方法加 threading.Lock + snapshot_* 方法。
- ProviderService 挂 SecurityGovernance 检查（默认策略放行全部，可配置封禁）。
- yfinance 两个 Provider 改 asyncio.to_thread；server.py 端点重活全部 to_thread；SQLite 加 WAL。
- server.py：CORS 收窄 localhost 白名单；可选 X-API-Key 鉴权中间件（含 WS）；WS 支持 ?task_id= 与 subscribe/unsubscribe 消息分级订阅。
- Planner 不再硬编码 gemini-3.5-flash，由 llm_config/默认决定；修复既存失败的 test_planner（mock 缺 status 字段）；修 utcnow 弃用；清理 backtest_skill 重复 import。
- 归档临时文件到 _archive/（_fu_*、日志、Untitled-1.txt）。
- 新增 faos/tests/test_e2e_workflows.py（路由一致性 + mock 全链路分析 + 回测节点执行）。最终 27 passed 全绿。
