## 修复 A 股分析数据缺失（应用户反馈）
- 用户分析 600176 时只拿到 EPS=0.96 + price=36.63，分析报告报文"API数据极度缺失"。
- 根因：DataRouter.detect_market 不认 `.SS`/`.SZ`/`.SH`/`.BJ` 后缀 → `600176.SS` 归为 `Unknown` → router 选 yfinance_quote（对 A 股数据极薄）而非 a_stock_direct（腾讯/东方财富直连，有 PE/PB/市值/K线）。
- 修复：detect_market 增加后缀识别（`.SS/.SZ/.SH/.BJ`）→ `600176.SS` 正确识别为 `A-Share` → 走 a_stock_direct（priority 200）→ 拿到完整行情+财务+117 天K线。
- 同时让 a_stock_provider 的 fetch 返回 quote 时自动附带 6mo K 线历史（先前只返回快照，Chart 和 Technical 分析缺乏历史数据）。
- 验证：600176.SS → A-Share ✔；a_stock_direct 返回中国巨石 price=36.63 PE=38.36 PB=4.65 cap=1454亿 + 117天K线 ✔。
- 用户配置 DeepSeek key 后仍报 "[LLM Error] All available LLM providers failed"。
- 经两轮排查找到两个 bug：
  1. **grounding_verifier 未导入**：`_call_openai_compatible` 第547行调用 `grounding_verifier` 但方法内未导入 → NameError → fallback 耗尽。修复：加局部 import（与 `_call_gemini` 一致）。
  2. **import os 作用域冲突**（本轮实际报错）：模块顶层已有 `import os`，但方法内 `if not api_key:` 块里又写了 `import os`，Python 编译器将 `os` 视为函数局部变量。用户提供了 API key 时该块不执行 → `os` 未绑定 → 第507行 `os.environ.get()` 抛 UnboundLocalError。修复：删除冗余的 `import os`。
- 验证：假 key 调 DeepSeek 收到真实 401 认证错误（`Authentication Fails, Your api key: ****-key is invalid`）→ 代码路径正常到达 DeepSeek API，非 UnboundError/NameError。
